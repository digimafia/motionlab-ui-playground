# MotionLab — Animated UI Playground

React 19 + Vite + TypeScript + Tailwind CSS 4 + Motion.

## Features

- Interactive live previews: async success button, spring button, floating card, staggered text, toggle and heart pulse
- Mobile/tablet/desktop viewport switcher
- Animation duration control and replay
- Favorites saved to localStorage
- Copyable curated Motion examples

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Vercel

Import `digimafia/motionlab-ui-playground` into Vercel. Select Vite, use `npm run build`, output directory `dist`.

Note: This MVP does not execute arbitrary pasted JavaScript. Examples are curated snippets.
